# منصة ألعاب المطابقة - Cloudflare Pages + JSON

## التشغيل المحلي
افتح `index.html` عبر إضافة Live Server في VS Code أو ارفع المجلد مباشرة إلى Cloudflare Pages.
> ملاحظة: بعض المتصفحات لا تسمح بقراءة JSON عند فتح الملف مباشرة من الجهاز بنظام file://، لذلك الأفضل Live Server.

## تعديل الأسئلة
عدّل الملف:
data/games.json

## النشر السريع على Cloudflare Pages
1. ادخل Cloudflare Dashboard.
2. Workers & Pages.
3. Create application.
4. Pages.
5. Upload assets / Direct Upload.
6. ارفع كامل محتويات هذا المجلد.
